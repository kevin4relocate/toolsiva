# Viewport-First Tool Layout

The tool workspace is now prioritized above the fold.

## Changes

- Tool pages use a maximum width of 92rem instead of 5xl.
- Breadcrumb, title and description spacing is reduced.
- Tool titles remain prominent but use less vertical space.
- Workspace padding and corner radius are reduced slightly.
- Editors use responsive heights based on the browser viewport.
- Two-column tools make better use of desktop width.
- Mobile layouts remain stacked and responsive.

## UX target

On a normal desktop or laptop viewport, users should see:

1. Breadcrumb
2. Tool title and description
3. Main controls
4. Most or all of the input workspace

without unnecessary scrolling before interaction.

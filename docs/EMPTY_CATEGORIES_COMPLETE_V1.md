# Toolsiva Empty Categories Complete v1

Adds 42 browser-side tools:

- 10 QR tools
- 12 calculators
- 20 unit converters

QR generation uses the `qrcode` npm package. Calculators and converters use no external APIs. All user input remains in the browser.

The existing header reads from `src/data/tools.ts`, so all new tools automatically appear in category dropdowns.

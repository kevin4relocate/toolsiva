# Smart Tool UX Rules

## Automatic tools
Counters, formatters, encoders, decoders, validators, text transforms, hashes,
HMAC, Basic Auth, password strength and hash comparison update automatically.
They do not show a generic Process button.

## Explicit action tools
Tools that create a new random value require an explicit action and use a
specific label: Generate password, Generate passphrase, Generate string,
Generate token or Generate UUIDs.

## Actions
Copy and Clear remain available above the workspace. A second compact action
row is shown below long result areas. Counter tools avoid the duplicate bottom row.

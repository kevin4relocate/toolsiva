# Toolsiva 100 Tools Complete v1

Adds 18 browser-only tools: 10 Text tools and 8 Calculators.

New Text tools: Line Counter, Sentence Counter, Paragraph Counter, Text to List,
List to Text, Remove Empty Lines, Add Line Numbers, Strip HTML Tags, Text
Repeater and Whitespace Visualizer.

New Calculators: Ratio, Proportion, Fraction, GCD/LCM, Pace, Unit Price, Profit
Margin and Markup.

The package brings Toolsiva from 82 to exactly 100 unique tools.

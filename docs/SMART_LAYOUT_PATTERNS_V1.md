# Smart Layout Patterns v1

Reviews all current Text, Developer and Security tools and assigns a suitable interaction pattern.

- Generators: compact options + generated result.
- Hash tools: input + compact digest card.
- Basic Auth: username/password form + header result.
- HMAC: message/secret/algorithm + signature result.
- Password strength: input + score meter.
- Hash compare: two compact inputs + semantic result.
- Developer converters: responsive dual pane.
- Validators: editor + semantic status and error location.
- JWT: token input + structured Header and Payload panels.
- Timestamp: compact input + converted values.
- Tool instructions: tailored by interaction pattern.

# Compact Layout + Header Tool Navigation v1

## What this package changes

### Compact tool pages
- Reduce overall content width to 84rem.
- Reduce hero spacing, title size and description size.
- Reduce section spacing below the tool.
- Reduce FAQ, related tool and how-to card padding.
- Make textareas shorter and more viewport-efficient.
- Reduce workspace padding for text, developer and security tools.

### Full tool dropdown navigation
- Desktop header now includes category dropdowns.
- Each dropdown lists all currently available tools in that category.
- Each category dropdown ends with a `View all` link.
- Mobile header includes a menu with accordion-style category groups.

## UX goal
- More compact pages.
- Faster access to tool controls.
- Easier navigation between tools without returning to category pages.
